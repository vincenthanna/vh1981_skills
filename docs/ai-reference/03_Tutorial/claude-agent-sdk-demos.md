Claude Agent SDK Demos

A collection of demo applications showcasing the Claude Agent SDK. Intended for local development and learning — not for production use.

## Demos

| Demo | Description |
|------|-------------|
| Hello World | Getting started with the Agent SDK |
| Hello World V2 | Using the Session API (`unstable_v2_*`) |
| Email Agent | IMAP-based email assistant |
| Excel Demo | Spreadsheet manipulation with Claude |
| Research Agent | Multi-agent system with parallel subagents |
| AskUserQuestion Previews | HTML preview cards for agent questions |
| Simple Chat App | React + Express chat UI with WebSocket streaming |
| Resume Generator | Web-search-based `.docx` resume generation |

## Installation

```bash
git clone https://github.com/anthropics/claude-agent-sdk-demos.git
cd claude-agent-sdk-demos
```

Each demo has its own directory with specific setup instructions.

## Requirements

- Bun runtime (or Node.js 18+)
- Anthropic API key (`ANTHROPIC_API_KEY`)

## Key Features

- Multi-agent coordination patterns
- Streaming over WebSocket
- HTML preview rendering
- V2 Session API examples
