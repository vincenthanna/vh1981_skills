Claude Cookbooks
Claude Cookbooks는 개발자들이 Claude로 구축하는 데 도움이 되도록 설계된 코드와 가이드를 제공하며, 프로젝트에 쉽게 통합할 수 있는 복사 가능한 코드 스니펫을 제공합니다.
사전 요구 사항
이 쿡북의 예제를 최대한 활용하려면 Claude API 키가 필요합니다(여기에서 무료로 가입하세요).
코드 예제는 주로 Python으로 작성되어 있지만, Claude API와 상호작용을 지원하는 모든 프로그래밍 언어에 개념을 적용할 수 있습니다.
Claude API를 처음 사용하는 경우, 먼저 Claude API 기초 과정을 수강하여 탄탄한 기반을 마련하는 것을 권장합니다.

기여하기
Claude Cookbooks는 개발자 커뮤니티의 기여로 발전합니다. 아이디어 제출, 오탈자 수정, 새 가이드 추가, 기존 가이드 개선 등 여러분의 의견을 소중히 여깁니다. 기여를 통해 이 리소스를 모두에게 더 가치 있게 만들 수 있습니다.
중복을 피하기 위해 기여하기 전에 기존 이슈와 풀 리퀘스트를 검토해 주세요.
새로운 예제나 가이드에 대한 아이디어가 있으시면 이슈 페이지에 공유해 주세요.

고급 기법

자동 평가(Automated evaluations): Claude를 사용하여 프롬프트 평가 과정을 자동화합니다.
JSON 모드 활성화: Claude에서 일관된 JSON 출력을 보장합니다.
콘텐츠 필터 생성: Claude를 사용하여 애플리케이션용 콘텐츠 모더레이션 필터를 만듭니다.
프롬프트 캐싱: Claude에서 효율적인 프롬프트 캐싱 기법을 배웁니다.
