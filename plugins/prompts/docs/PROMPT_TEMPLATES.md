## 템플릿 사용 팁

1. **변수 활용**: `{{variable}}` 형식으로 재사용 가능한 템플릿 만들기
2. **구체적으로**: 모호한 요청보다 구체적인 요청이 더 좋은 결과
3. **컨텍스트 제공**: 관련 파일, 기술 스택, 제약사항 명시
4. **결과 형식 지정**: 원하는 출력 형식을 명확히 지정
5. **단계별 요청**: 큰 작업은 여러 단계로 나눠서 요청
