cloud 모드로 동작할 때, 웹으로 실시간으로 현재 처리 중인 영상을 보여줄수 있는 기능을 추가하고 싶다.

계획 수정 요청:
- pipeline/components/probes/file_output.py 에서 bbox 등 meta 정보를 그린 프레임을 스트리밍해라.
- plan 내용을 markdown 파일로 저장해라. 이후 plan이 업데이트 될때마다 markdown 파일도 업데이트해라.

grid viewer 화면 구성 변경 요청:
- 출력 화면 구성을 변경하는 기능을 추가해달라.
  - full, 2x2, 3x3 …
  - dvr/nvr 에서 사용하는 다채널 화면 출력 기능을 가져오면 좋겠다.
- 카메라가 여러 개가 있다. (수백개 이상)

plan 검증 요청:
- plan의 내용에 서로간에 맞지 않는 부분들이 있는지 확인하고 있으면 fix.
- 명확하지 않은 부분들이 있는지 찾아보고, 그런 부분들이 있으면 내용을 더 업데이트하라.
- 수정 계획과 실제 코드가 잘 매치되지 않는 부분이 있는지 확인하라.
