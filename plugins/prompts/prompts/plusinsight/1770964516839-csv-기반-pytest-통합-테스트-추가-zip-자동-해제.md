테스트에 d-platform/tests/sample/timestamp_test_csv.zip 파일을 unzip 하고, 그 안의 csv 파일들을 읽어서 테스트하는 pytest case 추가해.

다음 조건을 검사:
- timestamp 뒤집어지는 부분이 있는지 check
- timestamp 중복이 있는지 check
- 위 두 개를 합쳐서 basic check 이런식으로 이름 붙여도 될듯
- CORRECTED 상태가 100 이상 지속되는지 확인
- Output timestamps must be monotonically increasing
- Interval deviation (avg) must improve over raw input
