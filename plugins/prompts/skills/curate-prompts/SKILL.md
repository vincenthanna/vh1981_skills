# curate-prompts

저장된 프롬프트들을 분석하여 재사용 가능한 고품질 프롬프트를 생성합니다.

## 입력
$ARGUMENTS

## 동작

### 1단계: 프롬프트 수집

```bash
# 모든 프롬프트 파일 목록
find prompts -name "*.md" -type f | head -50

# 또는 API로 조회
curl http://localhost:24123/api/prompts
```

### 2단계: 프롬프트 분석 및 평가

각 프롬프트를 다음 기준으로 평가하세요:

**재사용성 점수 (1-5)**
- 5: 프로젝트 독립적, 범용 패턴
- 4: 약간의 수정으로 재사용 가능
- 3: 특정 도메인에서 재사용 가능
- 2: 매우 프로젝트 특화
- 1: 일회성, 재사용 불가

**품질 점수 (1-5)**
- 명확한 목표/기대 결과
- 충분한 컨텍스트 제공
- 구조화된 요청
- 단계별 지시 포함

**패턴 분류**
- `verification`: 검증/테스트 요청
- `analysis`: 분석/진단 요청
- `design`: 설계/계획 요청
- `implementation`: 구현 요청
- `debugging`: 디버깅 요청
- `documentation`: 문서화 요청

### 3단계: 고품질 프롬프트 추출

재사용성 + 품질 점수가 높은 프롬프트에서:

1. **범용화**: 프로젝트 특화 내용을 `{{변수}}` 템플릿으로 변환
2. **구조화**: 목표, 컨텍스트, 기대 결과를 명확히 분리
3. **패턴화**: 유사한 프롬프트들의 공통 패턴 추출

### 4단계: 큐레이션 결과 저장

`prompts/curated/` 폴더에 저장

### 5단계: 결과 보고

- 분석한 프롬프트 수
- 추출한 패턴/템플릿 수
- 품질 분포

## 옵션

- `--repo <name>`: 특정 repo만 분석
- `--min-score <n>`: 최소 품질 점수 (기본: 3)
- `--dry-run`: 실제 저장 없이 분석만

## 사용 예시

```
/curate-prompts                        # 전체 분석 및 큐레이션
/curate-prompts --repo dp5             # dp5 repo만 분석
/curate-prompts --dry-run              # 분석만 수행
```
