# 일본어 표기 가이드라인

문서, 보고서, 답변에 일본어를 원문 그대로 적을 때 적용한다.
일본어 바로 뒤에 괄호를 열고 한글 발음을 적는다. 일본어를 읽지 못하는 사람도 그 말을 소리로 부르고,
원문(도면, 근무표, 화면 라벨)에서 같은 글자를 찾아 대조할 수 있게 하기 위해서다.

## 규칙

- 가나나 한자로 된 일본어를 적으면 바로 뒤 괄호에 한글 발음을 쓴다.
  예: 川崎(가와사키), スタッフエリア(스탓후에리아), 打刻(다코쿠)
- 발음은 일본어 원음을 한글로 옮긴다. 가타카나 외래어도 영어 원어가 아니라 일본어 발음을 적는다.
  예: スタッフ(스탓후), レジ(레지)
- 뜻이 필요하면 발음 뒤에 쉼표를 찍고 덧붙인다.
  예: 早番(하야반, 오전 근무조)
- 인라인 코드, 경로, 식별자 안의 일본어는 백틱을 닫은 뒤에 괄호를 붙인다.
  백틱 안에 괄호를 넣으면 리터럴 값이 바뀌기 때문이다. 예: `派1240`(하 1240)
- 코드블록 안에는 발음을 넣지 않는다. 필요하면 코드블록 아래 문장에서 읽는 법을 밝힌다.
- 같은 문단이나 같은 표 셀 안에서 같은 말이 반복되면 처음 한 번만 붙인다.
- 일본어 없이 한글로 옮긴 이름만 쓸 때(예: 가와사키 매장)는 이 규칙이 적용되지 않는다.

## 발음 적는 법

국립국어원 외래어 표기법의 일본어 표기를 따른다. 자주 틀리는 세 가지만 적는다.

- 촉음 っ(ッ)은 ㅅ 받침으로 적는다. 예: スタッフ(스탓후), 一緒(잇쇼)
- 장음은 따로 적지 않는다. 예: 東京(도쿄), ルール(루루)
- 어두의 か·た 행은 예사소리로 적는다. 예: 川崎(가와사키), 高田(다카다)

| 일본어 | 적는 법 |
|---|---|
| 大船 | 大船(오후나) |
| 有楽町 | 有楽町(유라쿠초) |
| ルミネ | ルミネ(루미네) |
| ジョブカン | ジョブカン(조부칸) |
| レジ会計 | レジ会計(레지카이케이) |
