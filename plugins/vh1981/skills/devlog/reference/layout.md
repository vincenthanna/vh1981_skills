# Project layout — reference

Detailed path and artifact-type reference for the `devlog` skill. The SKILL.md
body carries the core paths and the subtopic-folder trigger; this file is the
full table, read only when reorganizing a project.

## Path types

| Path | Purpose | Naming |
|------|---------|--------|
| `<project>/NN_<topic>.md` | Top-level investigation doc (one major topic) | `01_`, `02_` … 2-digit zero-pad |
| `<project>/<subtopic>/NN_<topic>.md` | Investigation docs grouped once a major topic spans many files | folder = slug; files re-numbered `NN_` within |
| `<project>/history/NN_<topic>.md` | Session work history (chronological) | `NN_` |
| `<project>/_archived/` | Superseded / obsolete docs, kept for the record | preserve original name |
| `<project>/README.md` | Project index | fixed name |
| `<project>/<topic>/data/<run>/` | CSV, logs, eval artifacts (non-markdown) | free; include a `RESULT.md` summary |
| `<project>/runs/`, `<project>/comparisons/` | Validation-campaign artifacts | defined by the validation command |

## Artifact taxonomy

| Type | Location | Purpose |
|------|----------|---------|
| investigation | `<project>/NN_<slug>.md` | analysis / design / RCA / result report — durable knowledge |
| history | `<project>/history/NN_<slug>.md` | session work flow / decisions |
| README | `<project>/README.md` | project index — auto-generated by `create` |
| validation-report | `<project>/NN_validation-<env>.md` | measurement results / pass-fail evaluation |
| external-draft | `<project>/NN_<external-draft-slug>.md` | external-facing drafts (PR comment, message); slug names it explicitly |
| data | `<project>/<topic>/data/<run>/` | quantitative artifacts; reference, don't inline; gitignore large files |

When the type is ambiguous, default to investigation. Mark external-facing
drafts explicitly in the slug (e.g. `04_pr-review-response.md`).
