# 완성 검사 목록

보고서를 넘기기 전에 전부 확인한다. ★ 는 기계로 확인되는 항목이고, 나머지는 눈으로 본다.

## 내용

- [ ] **0장 비유가 있는가.** 핵심 기전을 일상 사물 하나로 설명했는가
- [ ] **비유가 깨지는 지점을 같이 썼는가.** 읽는 사람이 바로 떠올릴 반례를 먼저 다뤘는가
- [ ] 1장만 읽고도 결론을 알 수 있는가 (KPI + 결론 3줄)
- [ ] 본문의 각 측정 절이 **어떻게 쟀나 → 결과 → 무슨 뜻인가** 순인가
- [ ] 표마다 숫자의 **뜻**을 설명하는 칸이나 상자가 있는가. 지표 이름만 적고 끝내지 않았는가
- [ ] **하지 말 것**에도 이유가 붙어 있는가
- [ ] "확실한 것 / 아직 모르는 것"을 분리했는가
- [ ] 한계를 본문에 썼는가 (표본 수, 판독자 수, 대리 지표 사용 등)

## 그림·애니메이션

- [ ] **절마다 그림이 최소 하나** 있는가. 숫자만 나열된 절이 없는가
- [ ] 보고서 전체에 그림이 **4개 이상**인가
- [ ] 각 그림이 **"이게 없으면 독자가 무엇을 놓치는가"** 에 답하는가 (장식이면 뺀다)
- [ ] ★ 전부 **인라인 SVG** 인가 (외부 이미지·CDN 0)
- [ ] 색을 의미로만 썼는가 (파랑=정상, 빨강=문제). 장식 색을 늘리지 않았는가
- [ ] **색만으로 구분하지 않았는가** (모양·위치·라벨 병행)
- [ ] 숫자를 그림 안에 직접 적었는가 (범례 추적을 강요하지 않았는가)
- [ ] `role="img"` · `aria-label` · `<figcaption>` 이 있는가
- [ ] 원형 차트를 쓰지 않았는가
- [ ] 0장 비유에 **단계 도식**을 썼는가

애니메이션:

- [ ] 움직임이 **설명 목적**인가 (단계 / 등장 / 비교 중 하나)
- [ ] **자동 반복이 없는가**
- [ ] 0.4초 이내인가
- [ ] **멈춘 상태가 최종 상태인가** — JS 를 꺼도 정보가 다 보이는가
- [ ] `prefers-reduced-motion: reduce` 에서 즉시 최종 상태가 되는가
- [ ] 인쇄했을 때 단계가 전부 펼쳐지는가
- [ ] 막대는 `data-w`, 선은 `data-len`, 숫자는 `data-to` 에 **최종값**이 들어 있는가
      (0 을 기본값으로 두면 JS 가 실패할 때 빈 그래프가 남는다)

## 검증 기록 — 빠뜨리기 쉬움

- [ ] **검증 기록 절이 있는가**
- [ ] 외부·하위 에이전트의 숫자 주장을 **직접 재계산**했는가
- [ ] 코드에 대한 주장을 `grep` 으로 확인했는가
- [ ] **재현 실패한 항목을 지우지 않고 남겼는가**
- [ ] 확인 못 한 것을 "미검증"으로 표시했는가
- [ ] 이 기록을 남기는 이유를 한 줄 적었는가

## 용어

- [ ] 용어집이 **이해하는 순서**로 배열됐는가 (가나다순 아님)
- [ ] 본문에서 설명 없이 쓴 낱말이 전부 용어집에 있는가
- [ ] 비유는 `<dd class="ex">` 에 넣었는가 (팝업에서 제외됨)
- [ ] ★ 용어 링크 수와 용어집 항목 수가 말이 되는가
- [ ] 팝업 문구를 **따로 적지 않았는가** (용어집에서 자동 생성되어야 함)
- [ ] 화면 좌·우 끝 용어와 **표 안 용어**에서 팝업이 보이는가 ← 실제로 깨졌던 두 지점

## 논문

- [ ] arXiv API 로 **번호와 제목이 일치하는지 직접 확인**했는가
- [ ] 제목이 일치한 것만 실었는가
- [ ] 각 항목에 3~4줄 요약이 있는가
- [ ] 각 항목에 **"이 보고서에서 — 어디에 썼는지"** 한 줄이 있는가
- [ ] 머리에 한계(수치는 원문 대조 안 함)를 적었는가
- [ ] ★ 인용 번호가 전부 존재하는 항목을 가리키는가
- [ ] ★ 인용되지 않은 참고문헌이 없는가

## 민감 정보

- [ ] ★ 이미지·data URI 가 0 인가
- [ ] ★ 외부 링크가 허용한 도메인뿐인가
- [ ] 내부 경로·계정·IP 가 노출돼도 괜찮은 범위인가
- [ ] 외부 호스팅(claude.ai 등)을 하려면 **먼저 물었는가**

## 호스팅

- [ ] 주제별 색인으로 올렸는가 (문서 하나만 띄우지 않았는가)
- [ ] 요청 경로를 파일 시스템에 넘기지 않는가 (허용 목록 방식)
- [ ] 민감 이미지가 든 문서가 기본 잠금인가
- [ ] 생존 확인이 **PID 파일 + 포트**인가 (`pgrep -f` 는 자기 명령줄을 매치한다)
- [ ] 재부팅 후 복구되는가 (`@reboot` cron 등)
- [ ] 사용자에게 **주소 · PID · 로그 위치 · 중지 방법**을 알렸는가

## 기계 검사 ★

```bash
python3 - report.html <<'PY'
import re, sys
h = open(sys.argv[1]).read()
ids  = set(re.findall(r'id="([^"]+)"', h))
anch = set(re.findall(r'href="#([^"]+)"', h))
refs = set(re.findall(r'id="(r\d+)"', h)); used = set(re.findall(r'href="#(r\d+)"', h))
print('끊긴 앵커  :', sorted(anch - ids) or '없음')
print('없는 인용  :', sorted(used - refs) or '없음')
print('미인용 문헌:', sorted(refs - used, key=lambda s: int(s[1:])) or '없음')
print('이미지     :', len(re.findall(r'<img|data:image', h)))
print('외부 도메인:', sorted({re.sub(r'(https?://[^/]+).*', r'\1', u)
                             for u in re.findall(r'href="(https?://[^"]+)"', h)}) or '없음')
print('용어 링크  :', len(re.findall(r'class="t" href="#g-', h)),
      '· 용어집 항목:', h.count('<dt id="g-'))
PY

# 스크립트 문법 (프로세스 치환은 node 가 못 읽으므로 파일로 뺀다)
python3 -c "import re;open('/tmp/t.js','w').write(re.search(r'<script>(.*?)</script>',open('report.html').read(),re.S).group(1))"
node --check /tmp/t.js
```

## 반응형·접근성

- [ ] 휴대폰 폭(약 400px)에서 가로 스크롤이 생기지 않는가 (표만 `.tw` 안에서 스크롤)
- [ ] 다크 모드에서 읽히는가
- [ ] 키보드 탭으로 용어 팝업이 뜨는가
- [ ] 인쇄했을 때 깨지지 않는가 (단계 도식이 펼쳐지고, 막대가 최종 폭인가)
