Claude Quickstarts
Claude Quickstarts는 개발자가 Claude API를 사용해 애플리케이션을 빠르게 만들 수 있도록 도와주는 프로젝트 모음이다. 각 quickstart는 필요에 맞게 쉽게 확장하고 커스터마이즈할 수 있는 기반을 제공한다.
Getting Started
이 quickstart들을 사용하려면 Claude API key가 필요하다. 아직 없다면 console.anthropic.com에서 무료로 가입할 수 있다.
Available Quickstarts
Customer Support Agent
Claude로 구동되는 고객 지원 agent. 이 프로젝트는 Claude의 자연어 이해 및 생성 능력을 활용해 지식 베이스에 접근할 수 있는 AI 기반 고객 지원 시스템을 만드는 방법을 보여준다.
Customer Support Agent Quickstart로 이동
Financial Data Analyst
Claude로 구동되는 금융 데이터 분석가. 이 프로젝트는 채팅을 통해 금융 데이터를 분석할 수 있도록 Claude의 능력을 인터랙티브 데이터 시각화와 결합하는 방법을 보여준다.
Financial Data Analyst Quickstart로 이동
Computer Use Demo
Claude가 데스크톱 컴퓨터를 제어하기 위해 사용할 수 있는 환경과 도구들. 이 프로젝트는 zoom action을 포함한 최신 computer_use_20251124 tool 버전을 포함하여 Claude의 computer use 기능 활용 방법을 보여준다.
Computer Use Demo Quickstart로 이동
Browser Tools API Demo
Claude로 구동되는 브라우저 자동화를 위한 완전한 레퍼런스 구현. 이 프로젝트는 Playwright를 사용한 navigation, DOM 검사, 폼 조작을 포함하여 웹 상호작용을 위한 Claude의 browser tools API 활용 방법을 보여준다.
Browser Tools API Demo Quickstart로 이동
Autonomous Coding Agent
Claude Agent SDK로 구동되는 자율 코딩 agent. 이 프로젝트는 여러 세션에 걸쳐 완전한 애플리케이션을 만들 수 있는 두-agent 패턴(initializer + coding agent)을 시연한다. 진행 상황은 git을 통해 저장되며, agent가 점진적으로 처리해 나가는 기능 목록을 사용한다.
Autonomous Coding Agent Quickstart로 이동
General Usage
각 quickstart 프로젝트에는 자체 README와 셋업 지침이 포함되어 있다. 일반적으로 다음 단계를 따른다:

이 repo를 clone한다
특정 quickstart 디렉터리로 이동한다
필요한 의존성을 설치한다
Claude API key를 환경 변수로 설정한다
quickstart 애플리케이션을 실행한다
