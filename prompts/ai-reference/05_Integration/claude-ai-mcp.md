Claude.ai MCP 통합
이 저장소는 Claude.ai의 MCP(Model Context Protocol) 통합을 위한 커뮤니케이션 허브입니다. 기술적 변경 사항을 확인하고 버그를 보고하거나 기능을 요청하는 데 사용하세요.
업데이트 받기
공지 사항만 받으려면 (노이즈 최소화):

Discussions로 이동하세요
Announcements 카테고리에서 Subscribe를 클릭하세요

다음 알림을 받을 수 있습니다:

새로운 MCP 기능

새로운 기능이나 개선 사항을 요청하세요

다루는 범위

통합(Integrations) - Claude.ai에 MCP 서버 연결
세션 관리(Session Management) - 초기화, 재연결, 라이프사이클 동작
프로토콜 지원(Protocol Support) - SSE, Streamable HTTP, 전송 변경 사항
도구 및 리소스 처리(Tool & Resource Handling) - Claude.ai가 MCP 도구를 검색하고 호출하는 방법
OAuth 및 인증(OAuth & Authentication) - MCP 서버의 토큰 처리

다루지 않는 범위

MCP 사양 자체 → modelcontextprotocol/specification
MCP SDK → modelcontextprotocol
일반 Claude.ai 이슈 (MCP 외) → support.anthropic.com
