Model Cards — Supplementary Materials

Claude Model Cards를 위한 보조 자료. Claude 모델 출시 동안 사용된 평가 prompt, 벤치마크 구성, 정책 파일을 담고 있다.

## Contents

### Claude Opus 4.5 (`claude-opus-4-5-20251101/`)

tau2-bench 평가를 위한 수정된 prompt 및 정책 파일:

- **Retail domain**: 수정된 retail 정책과 사용자 prompt
- **Telecom domain**: 수정된 telecom 정책과 사용자 prompt

이 파일들은 Claude Opus 4.5 출시 동안 사용된 구체적인 평가 구성을 문서화한 것이다. 전체 컨텍스트는 Claude Opus 4.5 System Card를 참조하라.

## Usage

이는 문서/데이터 전용 리포지토리이다. 설치가 필요하지 않다. Claude의 평가 방법론과 벤치마크 구성을 이해할 때 참고 자료로 사용할 수 있다.
