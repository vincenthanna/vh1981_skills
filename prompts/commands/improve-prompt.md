프롬프트를 Claude Code에서 더 잘 동작하도록 개선한다.

## 원본 프롬프트

$ARGUMENTS

## 개선 방향

1. **구조화**: 목표/컨텍스트/작업/규칙/출력 섹션으로 분리
2. **scope 명확화**: "수정 X", "분석만" 등 제약 조건 명시
3. **구체성 강화**: 모호한 표현을 구체적 기준으로 변환
4. **단계 분리**: 분석과 실행을 분리하여 중간 승인 가능하게
5. **출력 형식 지정**: 테이블, markdown, 파일 저장 등 명시
6. **규칙 추가**: 반복 실수를 방지하는 규칙 추가

## 작업

1. 원본 프롬프트를 분석하여 문제점/개선점 식별
2. 개선된 버전을 작성
3. 개선 이유를 간단히 설명
4. 확장 예시도 추가

## 규칙

- 원본의 의도를 변경하지 말 것
- 불필요하게 길어지지 않게 할 것
- markdown 포맷을 따를 것
