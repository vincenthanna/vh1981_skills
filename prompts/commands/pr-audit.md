현재 branch의 PR 수정내용을 감사하고 검증한다.

## 대상

$ARGUMENTS

대상이 비어있으면 현재 branch의 전체 commit을 대상으로 한다.

## 1단계: 분류 정리

PR의 모든 commit을 읽고, 대주제별로 분류하라.

주제별로:
- 해결하려는 문제
- 수정 내용 (최종 상태 기준, 중간과정 제외)
- 기대하는 결과

## 2단계: 검증

- 필요한 수정이 모두 이루어졌는가?
- 오류/버그가 있는가?
- 누락된 것이 있는가? (devlog/history 참고)
- 이전 PR의 수정이 무력화/원복된 부분이 있는가?

## 3단계: 코드 품질

- 디버깅용 코드가 남아있는가?
- 한글 주석이 남아있는가?
- 불필요한 import가 있는가?

## 규칙

- **수정하지 말고 보고만 하라.**
- 각 문제에 대해 파일:라인번호를 명시하라.
