검증-수정 반복 사이클을 실행한다.

## 검증 대상

$ARGUMENTS

## 절차

1. **전체 검증 실행**: 대상을 시뮬레이터/테스트로 검증
2. **결과 평가**: 평가 기준에 따라 pass/fail 판단
3. **문제 발견 시**:
   - 해당 시점 데이터 출력하여 원인 분석
   - 문서 + 코드 **동시에** 수정
   - 전체 재검증 (부분 검증 X)
4. **결과 보고**: 요약 테이블로 출력

## 규칙

- 평가 기준이 데이터 특성에 맞지 않으면 기준을 조정하고 이유를 보고
- 문서와 코드는 항상 동시에 수정하여 일관성 유지
- 각 반복 결과를 누적 기록
