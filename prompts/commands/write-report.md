분석/테스트 결과를 보고서로 정리한다.

## 주제

$ARGUMENTS

## 보고서 규칙

### 내용 원칙

- 최종적으로 발견/추론/판단한 **사실만** 포함
- trial & error 과정 제외
- 잘못된 것으로 판별된 내용 제외
- 원인으로 추정되었으나 아닌 것으로 판별된 것은 언급 X
- 코드 수정 내용 미포함
- 테스트 환경 구성 미포함

### 요약 (보고서 첫 부분)

- 3~5줄 요약
- 6하 원칙 기반, 원인과 결과 명확
- 요점만 간결하게 (산문체 X, 논문체 X)

### 형식

- markdown으로 저장
- 측정 결과에 분포 정보 포함 (avg, min, max, 백분위)
- 단위 명시 (ms, fps, % 등)
- 표를 적극 활용

## 작업

1. 현재 conversation에서 관련 데이터/분석 결과를 수집
2. 위 규칙에 따라 보고서 작성
3. 보고서를 markdown 파일로 저장
