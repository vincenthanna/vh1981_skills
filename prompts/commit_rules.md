commit 준비 혹은 commit 만들어라 등의 명령이 올 때 다음의 rule을 지킨다

<br>

### Rules

* * *

<br>

- markdown 파일은 commit 하지 않는다.
  - 단, **markdown이 주 자산인 repo는 예외로 한다**. 예시: `vh1981_skills` (prompt / skill / 문서 모음 저장소).
- \*.pem 등의 보안파일은 절대로 commit 하지 않는다.
- a.diff/b.diff 등의 차이점을 보기 위해 만든 임시 diff 파일들도 절대 commit 하지 않는다.
